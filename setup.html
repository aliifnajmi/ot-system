MULIA GROUP / OT SYSTEM V4

Sambungkan Supabase

Projek Supabase V4 telah ditetapkan kepada https://zehhsptclnigcjmbfgrn.supabase.co. Sambungan database hanya akan berfungsi selepas publishable key dimasukkan dan skema SQL dijalankan. Halaman ini menghalang aplikasi daripada memaparkan data contoh sebagai data sebenar.

1
Cipta projek Supabase

Buka Supabase Dashboard, cipta projek dan buka SQL Editor.

2
Jalankan skema database

Salin dan jalankan fail database/supabase_schema.sql.

3
Masukkan konfigurasi browser

Project URL sudah diisi. Masukkan publishable key sahaja dalam assets/js/supabase-config.js. Jangan masukkan service_role/secret key.

4
Wujudkan akaun dan profil aplikasi

Cipta akaun melalui Supabase Auth. Kemudian masukkan rekod user_profiles untuk pengguna tersebut dengan role admin atau technician.

Penting: jangan aktifkan production sebelum RLS diuji dan data lama dimigrasikan dengan betul.
